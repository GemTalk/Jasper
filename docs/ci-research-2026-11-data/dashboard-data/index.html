What is counted

Each point is a day with at least 3 passing test legs on a first attempt, on branches other than wip/* and throwaway/*. A leg is one operating system and GemStone version. Ubuntu and Windows legs include every GemStone version in the matrix that day. The run time is measured from the run start to the finish of its last job, for pull-request runs that passed. Merge-queue runs are left out because the queue can skip the tests. Weekends have no points. Data covers Sep 10 to Nov 12 2026.

The file and test sections come from one passing GemStone 3.6.2 leg per platform per week (30 legs), read from the test logs. One leg per week is a small sample, so single weeks can be off. Vitest prints only files and tests of about 1 second or more. The latest macOS sample for the supply-chain file shows 0 because it was taken after that file moved out of the legs.
