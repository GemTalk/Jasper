# Try a notebook

A **notebook** is a page of cells. Each cell holds some Smalltalk; run it with
**Shift+Enter** (or the ▷ button) and its result appears beneath it. Unlike a
workspace, the results stay on the page, and you can add Markdown cells for
notes — so a notebook is a good place to keep an exploration, or to write one up
for someone else.

- **Open Notebook** opens a blank notebook, ready for Smalltalk. It is also next
  to **Open Workspace** in the **Logins & Sessions** title bar.
- **Learn Smalltalk** opens a tutorial notebook: short lessons on Smalltalk's
  syntax, each followed by cells to run, ending with what makes GemStone
  different. It is also in a GemStone notebook's toolbar.

Cells run in the active session, like Display It. The notebook's kernel label,
top right, names the session. Notebooks are ordinary `.ipynb` files, so you can
save one and open it again later.
