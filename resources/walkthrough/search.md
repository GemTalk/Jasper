# Search your code

**GemStone Search** — `Cmd/Ctrl + Shift + A` — is one box that searches across
classes, methods, method source, and more. Start typing and results group by
category; pick one to open it.

It's the fastest way to answer "where is this?" when you don't yet know which
dictionary or class something lives in — no need to guess your way down the tree.

You can also search from the **GemStone Search** view (its icon in the sidebar),
which keeps your results and a preview pane open while you explore.
